# arcis.money

Landing page and application frontend for Arcis Protocol.

## Stack

Single-page HTML with embedded CSS and JavaScript. No build step required.

Roman antiquity design language. Cormorant Garamond serif typography. Obsidian and gold palette. Stone texture overlays. Latin inscriptions.

## Deploy

Static HTML. Drop `index.html` on any host.

For Vercel:
```bash
vercel --prod
```

For Cloudflare Pages, Netlify, or GitHub Pages: point at root.
